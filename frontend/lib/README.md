# Shared Web3 and contract layer

- chains.ts: local and Robinhood network metadata; active environment selection.
- web3.ts: Wagmi injected connector, provider discovery, SSR and transports.
- contracts.ts: central AMEAgent ABI, address and deployment-block configuration.
- generated/agent.ts: artifact ABI/runtime bytecode and local deployment data; generated by contracts:sync.
- agents.ts: verified deployment, onchain profiles, mint event decoding and event-derived ownership reads.
- mint.ts: shared mint lifecycle, confirmation and transaction errors.
- wallet-errors.ts: actionable wallet connection/request errors.
- environment.ts: validated production/development network selection and public RPC URL rules.
